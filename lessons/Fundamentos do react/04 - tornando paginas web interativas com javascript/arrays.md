# Arrays
Arrays são geralmente descritas como "lista de objetos"; elas são basicamente objetos que contem múltiplos valores armazenados em uma lista. Um objeto array pode ser armazenado em variáveis e ser tratado de forma muito similar a qualquer outro tipo de valor, a diferança está em podermos acessar cada valor dentro da lista individualmente, e fazer super úteiss e eficientes coisas com a lista.

## Exemplos de array
```javascript
    let shopping = ["bread", "milk", "cheese", "cookie", "noodles"];
```
```javascript
    let cities = {
        {name: "Los Angeles", population: 3792621},
        {name: "New York", population: 8175133},
        {name: "Chicago", population: 2695598}
    };
```
