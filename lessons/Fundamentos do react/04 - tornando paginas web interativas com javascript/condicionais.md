# Condicionais
As estruturas condicionais estão ligadas à tomada de decisão de um algoritimo. Ao utilizar expressões que retornam verdadeiro ou falso, o algoritimo executa o bloco de comandos relativo a este resultado.

## Estruturas condicionais básicas
- if
- else
- switch
- ternario

## Operadores Lógicos

| Operador | Siginificado |
|----------|--------------|
| &&       | AND (E)      |
| //       | OR (OU)      |
| == ===   | IGUAL        |
| != ou !==| DIFERENTE    |
| >        | Maior que    |
| <        | Menor que    |

## Exemplos básicos

```javascript
1 == 1
// True

1 === 1
// True

1 === "1"
// False

1 != "1"
// False

1 != 2
// True

1 == 1 && 2 == 3 && 3 == 3
// False

2 == 2 || 1 == 1
// True
```
