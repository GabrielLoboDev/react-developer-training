# O que é variáveis
Usamos variáveis como nomes simbólicos para os valores na aplicação. O nome das viariáveis, chamados de identificadores, obedecem determinadas regras.

Uma variável em JavaScript deve começar com uma letra, underlinde(_), os caracteres subsequentes podem também ser números (0-9). Devido JavaScript ser case-sensitive, letras incluem caracteres de "A" a "Z" (maiúsculos) e caracteres "a" a "z" (minúsculos).

## Declarações de variáveis
Existem três tipos de declarações em JavaScript.

```javascript
var name = "Gabriel";
let age = 25;
const APPROVED = true;
```
## Tipos de variáveis
```javascript
Boolean //true or false
null // null value"
undefined // undefined value
Number // 42 or 3.14159
String // "Gabriel"
```
