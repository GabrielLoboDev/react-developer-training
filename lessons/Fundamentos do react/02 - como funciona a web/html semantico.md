# HTML semântico

O HTML semântico é a forma de deixar o site com suas informações bem explicadas e bem compreensíveis para o computador, ajudando até mesmo em sua busca no Google e facilitando o entendimento de leitores de acessibilidade.

## Porque utilizar HTML semântico?

Além de facilitar a busca de forma orgânica e rankear sua página em mecanismos de busca, o HTML semântico ajuda os leitores de tela para deficiente visuais, facilitando seu compreeendimento. Ele, também deixa o código mais limpo e mais compreensível, tanto em organização como facilidade de visualizar uma tag específica só de passar o olho por ela.
