# Seletores em CSS

Os seletores são usados para direcionar os elementos HTML em nossas páginas da web que queremos estilizar.

## Exemplo de seletores

```css
h1
{
    color: blue;
    background-color: yellow;
}

p
{
    color: red;
}
```

### Tipo
```css
h1 {}
```

### Classe
```css
.box {}
```

### Id
```css
#unique {}
```

### Seletores de atributos
```css
a[title] {}

a[href="https://example.com"] {}
```
